# 🎄 Advent of Crode 2026 — Terminal Apps Advent Calendar

An advent calendar of terminal applications: one app per day, from **December 1st to December 24th, 2026**.

## Why "Advent of Crode"?

It's a wink to [Advent of Code](https://adventofcode.com/) — but *crode*, because it's **crade**: French for *dirty*, *grubby*, *quick and filthy*. 🧽

No elegant puzzle solutions here: just small, fun apps hacked together in a day. Clean code is optional; having fun is mandatory.

## The challenge

- Every day, build a **terminal-based application** (CLI, TUI, script… anything that runs in a terminal).
- It can be **useful** or completely **useless** — fun counts as much as utility.
- Keep it small: one day, one app.

## Layout

Each day lives in its own folder:

```
day-01/   → December 1st
day-02/   → December 2nd
...
day-24/   → December 24th 🎅
```

Each folder contains its app's source code and a `README.md` describing what it does, how to run it, and how AI was used to build it.
